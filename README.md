# QFF Hackathon Repository

This repository contains Phase 1 and Phase 2 work. The PS-P3 post-quantum cryptography benchmark is in `Phase 2/`.

## Open the Phase 2 project

From PowerShell at this repository root, enter the Phase 2 folder:

```powershell
Set-Location "Phase 2"
```

Then follow [Phase 2/README.md](Phase%202/README.md) for setup, benchmark commands, and result files.
